# 模型选型评测

给 `/api/models` 的「推荐模型」挑人选。**不靠综合榜单，只认本项目自己的任务。**

## 方法

复用生产链路的 prompt（`core.llm_agent.LLMAgent.parse_intent`），拿演示数据的
38 个变量 schema + 28 个模板注册表，跑 18 道有标准答案的中文路由题
（`test_cases.py`，其中 6 道是数据清洗类）。四个模型并发，各自串行跑完 18 题。

跑法（项目根目录）：

```bash
.venv/Scripts/python.exe eval/model_picker/run_pick.py
```

凭据从根目录 `apikey.txt` 读（该文件已在 `.gitignore` 内）。密钥只进内存，
不落日志、不缓存明文，缓存键用的是 sha256 前 12 位。

结果实时写入 `results/<时间戳>.json`，中途中断也不丢进度。

## 结果

### 2026-10-22（28 模板，18 题）

| 模型 | 准确率 | 平均延迟 | JSON 失败 |
|---|---|---|---|
| **gpt-6.1-sol** | **17/18 (94.4%)** | 17.7s | **0** |
| deepseek-v4-flash | 16/18 (88.9%) | 8.8s | 1 |
| glm-5.3-flash | 15/18 (83.3%) | 12.0s | 0 |
| qwen3.7-flash | 0/18 (0.0%) | — | 18 |

### 2026-10-15（13 模板，12 题）

| 模型 | 准确率 | 平均延迟 | JSON 失败 |
|---|---|---|---|
| **qwen3.7-flash** | **11/12 (91.7%)** | 22.1s | **0** |
| gpt-6.1-sol | 11/12 (91.7%) | 36.0s | 0 |
| glm-5.3-flash | 7/12 (58.3%) | 31.4s | 2 |
| deepseek-v4-flash | 5/12 (41.7%) | 10.7s | 7 |

### 怎么读这两张表

**qwen3.7-flash 在 10-22 是 0 分，但那不是它变笨了——渠道没了。**
18 次调用全部返回 HTTP 500「分组 auto 下模型 qwen3.7-flash 的可用渠道不存在」。
单独探测确认：它**仍然挂在 `/v1/models` 列表里**，只是调不通
（`_probe_qwen.py` 可复现）。

⚠️ 这条教训已经写进代码：**`/v1/models` 的存在性不等于可调用**，
所以 `model_catalog` 对策展层做一次真实探活（`probe_callable`），
只有明确调不通才标灰；探活自己没问出结果时不改判。

**deepseek-v4-flash 在两轮之间从 41.7% 跳到 88.9%。** 模型没换，
变的是中转站给它分配的渠道。对默认位来说这是减分项——
不能把一个会随供应商调度大幅波动的模型放在唯一依赖的位置上。

**gpt-6.1-sol 是两轮里唯一两次都拿第一的**（11/12 和 17/18），
且两轮都是 0 次 JSON 失败。这就是选它的理由，哪怕它更慢、更贵。

**deepseek-v4-flash 的 41.7% 不能直接当成"模型不行"。** 它成功那 5 次平均
10.7 秒，是四个里最快的；问题是 12 次里 7 次压根没回来（超时或返回空内容）。
这是中转站给它分配的渠道拥堵，模型本身未见得弱。

但它恰恰因此**不能当默认**：默认模型的头号指标是"每次都能给你个能用的答案"，
不是"跑通的时候有多快"。

**glm-5.3-flash 的错误是有模式的**——不管需求说什么，它都往 `hdfe` 上靠。
连"做个描述性统计"都能选成高维固定效应。这种系统性偏差比随机出错更值得警惕。

## 结论

推荐默认 = `gpt-6.1-sol`，写死在 `core/model_catalog.py` 的 `RECOMMENDED_MODEL`。
（2026-10-15 时是 `qwen3.7-flash`，10-22 该渠道下架后改的。）

**这个值不随中转站的 `/v1/models` 自动漂移。** 远程列表只用来补充"还有什么能选"，
推荐位只认策展清单。否则供应商上架什么、下架什么，用户的默认值就跟着变。

## 什么时候该重跑

- 换中转站 / 换供应商
- 模板库加了新模板（路由的候选集变了，混淆关系也变）
- 距上次评测超过半年

代价：几十次 API 调用，几块钱，十来分钟。
