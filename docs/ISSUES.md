## #1 BYOK 缺接口地址输入，密钥模式设计需再斟酌

**现象**：设置页的"自带密钥"只让填 key。用户用的都是中转站，key 和 URL 是绑定的——
不知道 URL 的人就算去申请了别家的 key 也没法用。

**根因**：后端 `cloud/keys.py:resolve()` 其实已支持请求体带 `api_url`（缺省用站点地址），
协议 3.5 也写了；但云端前端设置页只做了 key 输入框，URL 能力没暴露。

**方案**：
- 设置页 BYOK 区加"接口地址"输入（留空 = 用站点配置的地址），存 localStorage，
  随 `/api/plan`、`/api/llm/status`、`/api/llm/models` 一起带上。
- 文案说明三种情况：同一中转站的 key（不用填）/ 别家中转站（填它的地址）/
  OpenAI 官方 key（填官方地址）。

**状态**：✅ 已解决（2026-11-03）

## #3 任务详情页导出生成的 .do 脚本与执行日志

**现象**：用户想把生成的 .do 和执行日志下载留档（写论文/复现要用），页面上只能看不能下。

**根因**：不是数据缺失——tasks 表本来就存了 `do_script` 全文与 `log` 全文，
详情页也在展示；缺的是下载入口。

**方案**：
- 后端：`/api/tasks/<id>/script` 返回 .do 附件下载（现有 log 接口加 `download=1` 支持附件模式）。
- 前端：详情页".do 脚本"块与日志块各加下载按钮。

**状态**：✅ 已解决（2026-11-03）

## #4 上传的数据集名字被自动改名（incoming_xxxxxxxx.dta）

**现象**：在数据集页上传 `xxx.dta`，新建任务页里数据集下拉显示的名字和原文件名不一样。

**根因**：浏览器上传走本机代理（5100），代理先把文件存成临时名
`incoming_{8位随机}.dta`（`agent/agent.py` 的 upload_dataset），
再拿**临时文件名**去云端注册（`register_local_dataset(tmp)` 内部用 `dta_path.name`）。
所以云端记的名字就是临时名。

**方案**：`register_local_dataset()` 增加 `display_name` 参数，注册一律用浏览器带来的
原始文件名；临时文件名只用于本机落盘。顺手在注册时做名字去重提示（同名覆盖判断）。

**状态**：✅ 已解决（2026-11-03）
